# タイムセーバー プライバシーポリシー

制定日: 2026年10月20日

改定日: 2026年11月10日

石井公隆(以下「運営者」)は、iPhone アプリ「タイムセーバー」(以下「本アプリ」)での利用者の情報の扱いを、次のとおり定めます。

## 1. 基本の考え方

本アプリは、運営者のサーバーと通信しません。本アプリが扱う情報は、利用者の iPhone の中だけに保存し、iPhone の中だけで使います。運営者が利用者の情報を受け取るのは、利用者がお問い合わせのメールを送ったとき(4.)と、Apple を通じてクラッシュの情報が届くとき(3.)だけです。

広告は表示しません。利用者を追跡する仕組み(トラッキング)や、利用状況を集める解析のサービスも使いません。

## 2. iPhone の中で扱う情報

本アプリは、機能を動かすために次の情報を扱います。どれも iPhone の中だけに保存し、運営者には送りません。

| 情報 | 使う目的 |
|---|---|
| スクリーンタイムの利用時間 | 予算の残り・グラフ・振り返りを出すため。利用時間は、Apple のスクリーンタイムの仕組みの中で集計・表示し、本アプリの外には出しません |
| 選んだアプリ・Webサイト・カテゴリ | 予算やブロックの対象にするため。Apple から渡される識別子で扱い、アプリの名前そのものは保存しません |
| 予算・前借り・ブロックのルール・時間割・テスト期間・集中タイマーなどの設定と記録 | 各機能を動かすため |
| 場所のルール・通学区間で選んだ地点と駅の位置 | その場所への出入りでブロックを切り替えるため。出入りの記録は直近10件だけ残し、緯度・経度は記録に残しません |
| 見ていない期間の記録 | 記録を表示するため。iPhone の中で暗号化して保存し、開くときは Face ID(またはパスコード)で確かめます。ウィジェットと通知には出しません |
| 「Plus」を利用中かどうか | 有料の機能を使えるようにするため |

位置情報は、利用者が場所のルールまたは通学区間を作り、許可したときだけ使います。iPhone の地域の監視の仕組みを使い、連続して位置を測ることはしません。地点を選ぶ画面で「現在地」を押したときだけ、その場で1回、位置を測ります。

## 3. Apple のサービスに送られる情報

次の場合は、Apple のサービスに情報が送られます。その扱いには、Apple のプライバシーポリシー(https://www.apple.com/jp/legal/privacy/)が適用されます。

- **駅名や場所を名前で探すとき:** 入力した文字が、Apple のマップの検索に送られます。
- **Plus の購入・復元・解約:** 支払いは App Store で行われ、運営者は支払いの情報(カードの番号など)を受け取りません。本アプリは、購入が有効かどうかを iPhone の中で確かめるだけです。
- **クラッシュの情報:** 利用者が iPhone の設定で「解析データを App デベロッパと共有」をオンにしている場合、本アプリが異常終了したときの技術的な情報が、Apple を通じて運営者に届くことがあります。個人を特定する情報は含まれません。

## 4. 利用者が自分で送る・投稿するとき

次の場合は、利用者が操作したときだけ、情報が本アプリの外に出ます。本アプリが自動で送ることはありません。

- **お問い合わせ:** 設定タブの「お問い合わせ」では、本アプリは利用者のメールアプリに下書きを作るだけで、送るかどうかは利用者が決めます。送られたメールで運営者が受け取るのは、送り主のメールアドレス・お問い合わせの種類と内容と、「アプリと iOS のバージョン・機種を添える」がオンのときはその情報です。利用時間などの記録は入れません。運営者は、受け取った情報を、返信・不具合の調査・本アプリの改善にだけ使います。メールは、利用者と運営者が使うメールのサービス(運営者は Microsoft の Outlook)を通じて届きます。
- **貯金を X に投稿する:** ストーリー用の画面で「Xに投稿する」を押すと、先週の貯金の時間と連続記録を書いた定型文が、X の投稿画面に渡されます。使った時間・予算・アプリの名前は入れません。投稿するかどうかは利用者が決め、投稿した内容の扱いには X のプライバシーポリシーが適用されます。

## 5. 本アプリが使わないもの

- 写真へのアクセスの許可は求めません。時間割の画像を読み取る機能では、利用者が選んだ画像だけを、iPhone の中の文字認識で読み取ります。画像と読み取った文字は保存しません。
- Face ID の顔の情報を、本アプリが受け取ることはありません。確認は iPhone が行い、本アプリは結果(確認できたかどうか)だけを受け取ります。
- 通知は iPhone の中で作ります。通知の文面に、成人向けサイトのフィルタや記録の内容に触れる言葉は入れません。

## 6. 第三者への提供

iPhone の中の情報は運営者が受け取らないため、第三者に提供することもありません。お問い合わせで受け取った情報は、法令にもとづく場合を除いて、第三者に提供しません。

## 7. 保存期間と削除

本アプリの情報は、利用者が本アプリの中で消すか、本アプリを iPhone から削除すると消えます。ただし、iPhone のバックアップ(iCloud バックアップやパソコンへのバックアップ)をとっている場合は、そのバックアップの中に残ることがあります。

お問い合わせのメールは、対応が終わったあとも、同じ内容のお問い合わせに答えるために保管することがあります。消してほしいときは、10. の連絡先にお知らせください。

## 8. 子どもの利用

本アプリは、利用者本人が自分のために使うアプリで、主に大学生を対象にしています。子どもを見守る・保護者が管理するためのアプリではありません。

## 9. このポリシーの変更

本アプリの機能の変更などにあわせて、このポリシーを変えることがあります。大きく変えるときは、本アプリの更新内容またはこのページでお知らせします。変えた日は、このページの上の改定日に書きます。
